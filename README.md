# 청강 교원 역량진단 웹앱 (목업)

전임교원 역량진단 운영안 v5의 **공통 4수준 척도(기초 수행–기대수준 충족–변화 기여–전문성 공유·지원)** 로
"이런 방식으로 자가진단을 개발·테스트해 보겠다"를 보여 주는 목업입니다.

## 열어 보기
`dist/index.html`을 브라우저에서 엽니다. (서버 불필요)
- 처음에는 로그인 없이 **전임교원의 자기진단 입력 화면**(작성 중인 최도현 교수)이 바로 열립니다. 상단 `체험 계정`에서 다른 교원으로 바꿀 수 있습니다. 헤더 오른쪽 `전임교원 보기 / 관리자 보기`로 전환합니다.
- 시연 데이터: 김교수(평가 통보까지 완료), 박지연(제출·평가 대기), 최도현(작성 중), 정수진(미시작), 이평가(평가자).
- 관리자 메뉴 `데이터·기록 → 시연 데이터로 초기화`로 처음 상태로 되돌립니다.

## 목업이 보여 주는 것
1. 6개 역량 × 12문항 × 공통 4수준 자기진단 — **역량 탭을 자유롭게 오가며 입력**(순서 제한·저장 버튼 없음, 자동 저장), 수준은 선택 카드로 고름 (현재 수준·2년 뒤 목표, `기초 수행 전`·`역할 해당 없음`·`수행 기회 없음` 상태)
2. **업무 기록으로 행동기준 확인** (`기록으로 확인하기`, 가상 기록) — 교원이 평가용 서류를 따로 쓰지 않는 방향
   - 자가진단 화면은 **점진적 공개**: 현재 수준과 2년 뒤 목표를 좌우로 비교하는 화면에서, 수준 카드를 클릭하는 순간 그 수준의 상세 행동기준 설명 칸과 다음 행동을 안내하는 칸(2년 뒤 목표 → 행동기준 확인·사례·다음 문항)이 생성됨. 클릭 전에는 현재 수준 카드만 보임
   - 메뉴는 4개: `자가진단 / 진단결과 / 도움말 / 운영자기능` (평가자는 진단결과 안의 `평가 대상자` 탭, 운영 세부 화면은 운영자기능 안의 탭)
3. 자기진단 → 평가자 판정(자기점수 비공개, 기록 신호만 참고) → 통보 → 이의제기 → 면담
4. 관리자: 회차·구성원·평가자 담당 지정·진행 현황·**측정 일치도**(자기진단↔기록 추정↔평가자 확인)
5. `파일럿 안내`: 목업과 실제 구축의 차이, 6월 파일럿에서 검증할 것

## 목업의 한계 (실제 구축에서 바뀌는 것)
저장은 브라우저(localStorage), 로그인은 체험용(`SKIP_LOGIN`, `dist/core.js`), 일상 기록은 가상입니다.
실제 파일럿에서는 서버 저장, 학교 계정 연동, 학내 시스템(상담일지·결재 등) 연동이 필요합니다.

## 구성
- `dist/questions.js` 12문항(운영안 v5 부록에서 생성, 문항별 `signals` = 기록 신호 예시)
- `dist/theme.css` 전체 스타일(색 체계·사이드바·수준 선택 카드·역량 탭·하단 액션 바). 이전 `style.css`·`workspace.css`·`extras.css`는 더 이상 쓰지 않음
- `dist/core.js` 데이터·시연 시나리오·공용 UI / `user.js` 교원 화면 / `review.js` 평가자 화면 / `operations.js` 관리자 화면 / `app.js` 라우터
- `tests/` 자동 테스트(jsdom): `cd tests && npm i && npm test`
- `dist_v5_before_mock/` 이번 개편 직전 상태 백업 (이전 5수준 버전 포함)
